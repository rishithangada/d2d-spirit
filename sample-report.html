Executive Summary

The application is broadly well-configured but two issues expose it to practical attack paths. The API returns verbose stack traces on error, leaking framework internals an attacker can use to target known CVEs, and the login endpoint has no rate limiting, leaving it open to credential stuffing against the customer base. The single highest-priority fix is to suppress verbose API errors in production and add lockout on authentication.

Scope & Methodology

  • Web application — open ports, TLS/SSL, security headers, cookies
  • API surface — docs/schema exposure, CORS, verbose errors, rate limiting

All testing was non-destructive and conducted under written authorization and defined scope.

Findings & Remediation

HIGHAPI returns verbose stack traces on error
Evidence: GET /api/v1/orders/%27 -> 500 with full Django traceback + settings
Remediation: Return generic error responses in production; log stack traces server-side only.
Disable debug output in production; never expose stack traces to clients.
HIGHNo rate limiting on /api/v1/auth/login
Evidence: 120 requests/10s accepted with no throttling or lockout
Remediation: Add rate limiting / lockout on auth and sensitive endpoints to blunt credential-stuffing.
MEDIUMCORS policy allows arbitrary origins
Evidence: Access-Control-Allow-Origin: * on /api/v1/users
Remediation: Replace Access-Control-Allow-Origin: * with an explicit allow-list of trusted origins.
MEDIUMMissing X-Frame-Options / frame-ancestors (clickjacking)
Remediation: Set X-Frame-Options: DENY (or a CSP frame-ancestors directive).
MEDIUMMissing Strict-Transport-Security header
Remediation: Set Strict-Transport-Security: max-age=31536000; includeSubDomains.
LOWServer version disclosed in response headers
Evidence: Server: nginx/1.18.0
Remediation: Suppress server/framework version banners in response headers.
LOWMissing Content-Security-Policy header
Remediation: Review and remediate per security best practice.
INFOTLS 1.2 supported; TLS 1.3 recommended
Remediation: Enable TLS 1.3 and disable legacy protocol/cipher suites.
